Create internal texture mapping app, that maps image stitches to a part of 3D model. Also allowing users to localise defects from 2D images to 3D space through the mapping. AKA “Internal Column Stitching Tool”.

Tech stack includes: Vue + Vuetify, Python + flask, MongoDB, Docker

Features include:
- Visualizing points on Cesium
- Create 2D to 3D mapping from images
- Localisation of detected defects
- Streamlined inspection flow for colleagues' usage
