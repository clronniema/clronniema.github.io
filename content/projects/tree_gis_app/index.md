The GIS system is a combination of GIS system, tree assessment, RFID reader integration and tree management system, it consists web and mobile application. My duty at first was to develop the mobile application, eventually moving to Oracle database data cleaning, interfacing and assisting in web application development when needed. 

{{< figure src="android_map.png" title="Mobile tree map" lightbox="true">}}

One of the exciting features was to allow visualization of trees in the system. The tree points are displayed on top of a pre-generated mobile basemap packages. Users are also allowed to add or amend tree locations.
